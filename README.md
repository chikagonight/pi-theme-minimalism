# pi-theme-minimalism

Минималистичный кастомный футер для [Pi](https://pi.dev) (`@earendil-works/pi-coding-agent`):
каталог + git-ветка слева, текущая модель по центру, токены сессии / использование контекста / статус MCP-серверов справа.
Цвет каждого элемента настраивается отдельно. Над строкой ввода также отображаются лимиты провайдеров.

## Что показывает футер

```
~/project (main)             claude-opus-4-5 · medium            ↑12.3K ↓4.1K  76.3K/1M  MCP:2/5
```

- слева: текущий рабочий каталог (`~` вместо home) и git-ветка в скобках, если каталог — репозиторий;
- по центру: название текущей модели и, если задан, уровень thinking (`model · level`); при узком терминале модель переносится на вторую строку;
- справа: input/output токены сессии, использование контекста (`used/window`), статус MCP-серверов
  (`MCP:N/M`, где N — сервера с видимыми tools, M — включённые сервера из `mcp.json`); текст статуса
  зелёный, если все сервера подключены, иначе красный.

## Лимиты провайдеров

Виджет над строкой ввода показывает остаток и максимум запросов (`req`) и токенов (`tok`)
по каждому провайдеру. Данные поступают из заголовков ответов Anthropic и OpenAI; для прочих
провайдеров (включая OpenRouter) распознавание этих форматов работает best-effort.
Виджет накапливает последние доступные значения за текущую сессию и скрыт, пока данных нет.
Все провайдеры отображаются в одной строке (блоки разделены двумя пробелами), например:
`anthropic 5h|█░░░░|22%|3h46m||wk|░░░░░|2%|6d  openai-codex 5h|░░░░░|8%|4h37m||wk|█░░░░|20%|4d`.

## Установка

Расширение — обычный TypeScript-файл Pi. Самый простой способ — симлинк в пользовательскую
директорию расширений:

```bash
ln -s "$(pwd)/custom-footer.ts" ~/.pi/agent/extensions/custom-footer.ts
ln -s "$(pwd)/pi-theme-minimalism" ~/.pi/agent/extensions/pi-theme-minimalism
```

Футер активируется автоматически при старте Pi (`session_start`), без команды.

## Настройка цвета

Создайте (не коммитьте) файл `~/.pi/agent/pi-theme-minimalism/colors.json` — все поля опциональны,
значение — либо имя foreground-токена активной темы Pi (`dim`, `muted`, `text`, `accent`, `success`,
`error`, ...), либо hex-цвет `"#rgb"`/`"#rrggbb"`:

```json
{
  "cwd": "muted",
  "branch": "muted",
  "model": "accent",
  "tokens": "muted",
  "context": "muted",
  "mcpOk": "success",
  "mcpBad": "error",
  "limitsProvider": "dim",
  "limitsAnthropic": "#D97757",
  "limitsCodex": "#4A90E2"
}
```

Цвет `model` относится только к центральному блоку (модель и уровень thinking); по умолчанию — `accent`.
Блок Anthropic окрашен через `limitsAnthropic` (по умолчанию `#D97757`), OpenAI Codex — через
`limitsCodex` (по умолчанию `#4A90E2`). Для остальных провайдеров используется
`limitsProvider` (по умолчанию `dim`).
См. `colors.example.json` как шаблон. Конфиг перечитывается на каждом рендере футера и виджета —
изменения применяются без перезапуска Pi. Отсутствующий файл или невалидный JSON — используются
дефолты из примера выше. Невалидное значение одного поля откатывается к дефолту только для этого поля.

## Разработка

Чистая логика (форматирование чисел, цветов, подсчёт MCP-серверов) вынесена в
`pi-theme-minimalism/helpers.ts` и `pi-theme-minimalism/provider-limits.ts` и покрыта тестами на `node:test`:

```bash
node --test pi-theme-minimalism/custom-footer.test.mjs
node --test pi-theme-minimalism/provider-limits.test.mjs
```
